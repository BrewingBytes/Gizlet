# Deferred work

Items that were deliberately not done, with the reason and the condition that would
change the answer. An item here is a decision, not a backlog entry — anything with a
scope and acceptance criteria belongs in a GitHub issue instead.

## GitHub reaction counts on the not-built-yet list

**Deferred.** Once the request form has produced issues, the only honest demand counter
is GitHub reaction counts baked in at build time, because a reader can click through and
audit them.

**Why not now:** do not ship a counter before there is something to count — a zero beside
nine Gizlets reads as nobody cares. It would also add a build-time GitHub API dependency
to a static build.

**Revisit when:** planned Gizlets have accumulated requests, and the roadmap page ships.
