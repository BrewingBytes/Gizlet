### Added

- **Compress, Resize and Convert now take a batch.** Choose or drop up to 25 images, set the controls once, and every picture is processed on this device in turn — each with its own download and all of them as one ZIP. A file the browser cannot decode costs that one row rather than the run.
- **Image Flows run over a batch too.** An image flow accepts several starting pictures whatever its chain, runs every step over each of them, and hands back the set as one archive. A picture a step cannot do is listed with its reason beside the ones that finished.

### Changed

- Resize applies one set of numbers to a batch the way each picture needs it: a percentage scales every picture, an exact width with proportions kept lets each picture work out its own height, and turning proportions off forces every picture to the same box. The workspace says which of the three is about to happen.
