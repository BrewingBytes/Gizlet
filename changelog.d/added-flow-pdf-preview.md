- A flow that ends in a PDF now shows the document it produced in its result panel, page by page, with previous, next, and a page jump — the same thing the panel has always done for an image result. A visitor who chains images into a PDF can see the page order and what automatic orientation did to each sheet while there is still time to change them, instead of having to download the file to find out. It is the finished document that is drawn, and the page turning is the shared `src/scripts/pdf-page-view.ts` the two PDF workspaces already use. pdf.js is loaded only once a run has made a PDF, so the flows page's initial JavaScript is unchanged for a visitor whose flow never makes one, and a preview that will not draw says so and leaves the download alone.
