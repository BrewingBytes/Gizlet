- **A CSV Viewer Gizlet**, at `/tools/csv-viewer/`: open a delimited file and see what is actually in it. A table with the header row along the top, one row per record, and the line of the file each row starts on down the side — drop the file in or paste the text, either way it is opened and read by this browser. It needed no new way to read a CSV: the RFC 4180 reader and writer are the ones the JSON and CSV Converter already uses, so the two cannot disagree about what a quote means.
- **The separator is worked out, and then said out loud.** Comma, semicolon, tab and pipe are each tried against the document and the reading the most rows agree about wins, and the page says which one it read the file with and how many columns that gave — because a guess you cannot see is a guess you cannot correct. Choose one yourself and that is the answer until another file arrives. The converter next door still asks rather than guessing, and the difference is the point: a table can show you the guess was wrong, and a conversion cannot.
- **A row that disagrees with its header is shown rather than refused.** One that stops short is drawn with empty cells; one with a field too many makes the table wider than its headings and puts the extra value in a column with no name. Both are marked in the table, in a word rather than only a colour, and named by the line they are on — which is what turns "this export is broken somewhere" into "line 4,118". A converter has to refuse that row because it has no column for it; a viewer has one, on screen.
- Whether the first row names the columns is a switch, because a CSV has no way of saying. Turn it off for an export that begins with data and the columns are numbered instead, so no record is quietly swallowed by a heading the file never had.
- **Underneath the table is the same document written back out tidily**, to copy or download, named after the file it came from. A value is quoted when, and only when, it holds the separator, a double quote or a line break; every row is written the same width; every line ends CRLF, which is what the standard names and what a spreadsheet on Windows still wants. Nothing is trimmed, renamed, reordered or reinterpreted on the way through, and the page says when the tidied copy is not the one you opened character for character.
- **A large export is read whole and drawn in part.** The table stops at 200 rows and 50 columns and says how much of the document that is, because drawing a hundred thousand rows of cells is how a tab stops responding — and the tidied CSV underneath is still all of it. A document over 8 MB is refused rather than half-read, and an `.xlsx` is named as the ZIP archive of XML it really is instead of being shown as a screen of replacement characters.
- Your document stays on this device. It is opened, parsed and drawn by this browser, and the file you download is written by the page out of the text already on screen. That matters more here than it looks: a CSV is usually the most sensitive file somebody owns without thinking of it that way — a customer list, an order export, a payroll run — and the ordinary way to look at one online is to hand it to a site that receives it.
