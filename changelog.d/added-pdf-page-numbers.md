- PDF Page Numbers is built. Write numbers onto a document that arrived without them: four formats, six positions — all of them edges, because a page number in the middle of the page is not a page number — a size, a margin in points, the number to start at, how many pages to skip at the front, and a range. The numbers are drawn onto the existing pages rather than rebuilt, so text stays selectable, images are not re-encoded, and nothing already on the page is touched. Your original file is not modified: the numbered document is a new file.
- The three settings about counting compose in one order, and the preview shows the result before anything is written: the skipped pages at the front go first, the range narrows what is left, and the numbering then counts from the starting number across whatever survived. Numbering pages 5 to 8 of a report starting at 1 gives 1 to 4, because that is what was asked for rather than an offset to work out. A total such as "of 10" counts the numbers actually printed rather than the document's pages, so a reader counting the numbered pages gets the same answer.
- A page carrying its own rotation gets its number where it can be read, using the same correction the watermark uses rather than a second copy of it, and the preview reads the same placement function the writer does — so what is on screen is where the number lands. PDF Page Numbers is also a Flow block: a chain numbers the whole document from one, because a skip or a range is about a particular document and a chain does not know which document will reach it.
