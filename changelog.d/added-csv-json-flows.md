- **Gizlet Flows carries records now, not only pixels and pages.** Two new categories, CSV and JSON: choose a delimited document or a JSON file and chain the Gizlets that read one. `Your CSV → CSV Viewer → JSON and CSV Converter` hands back JSON, and the same three blocks starting from a JSON file hand back a table. The document is read as it is chosen, in this browser, and every block after that works on what is already in the tab.
- **The two-way converter is one block that runs whichever way the chain hands it.** Nothing asks and nothing is set: a block given a table reads it, a block given JSON writes one, and what may follow it is whatever reads the payload it just made — including itself, going back. A Gizlet can now declare the same job in reverse, which is the sentence the compatibility graph could not say before and the whole reason this Gizlet was left out of it.
- **CSV Viewer is a step rather than a look at something.** What it hands on is the tidied document — quoted on RFC 4180's rule, every row the same width, every line CRLF — so a chain can pass a repaired file to whatever refused the original. That is what makes it a block at all: the PDF viewer has no place in a flow because looking at a document produces nothing, and tidying one produces a document.
- JSON Formatter joins the same lineage without a new contract; it declared `json-text` long before anything carried it. In a chain it indents, and the minifying half stays on its own page, where something is actually asking for it.
- **A shared flow link still carries no document, and carries no setting for any of these blocks.** The separator is read off the file that arrives, the direction a conversion runs is decided by the payload that reaches the block, and a cell is read as text — the reading that cannot lose a leading zero. A link that named any of those would be asserting something about a document it has never seen. A link now also drops the image format for a chain with no image in it.
- Dropping a `.csv` or a `.json` file on the home page names the Gizlets that read it, the same way dropping a photograph or a PDF already did.
- A flow reads a text document of up to 8 MB, the ceiling CSV Viewer already kept, and refuses one that is not what it says it is while it is still being chosen: a spreadsheet is named as the ZIP archive it is, and a file that is not valid JSON is refused with the position of the problem rather than failing halfway through a chain.
