- `pnpm run pr:assets -- <image>…` publishes a pull request's screenshots to the `pr-assets` branch and prints the markdown that embeds them. The screenshot rule in [AGENTS.md](AGENTS.md) already said where those images live; getting them there by hand was a dozen git plumbing calls, rediscovered on every pull request. The script checks nothing out and switches no branch, and commits on top of what the branch already holds, so another pull request's images survive.
