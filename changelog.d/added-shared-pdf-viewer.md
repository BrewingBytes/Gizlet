- Every PDF Gizlet now reads documents through the same viewer. The PDF Viewer stopped being a one-off Gizlet and became the document surface for the whole PDF half of the site: one markup block, one stylesheet, one set of controls. A visitor learns thumbnails, page navigation, the page field, zoom and full screen once, and finds them everywhere — and the PDF Viewer itself is now that surface plus a file picker rather than a special implementation nobody else could use.
- Full screen is new, and it never does nothing. Where the browser has element full screen it uses it, with the platform's own exit gesture; where it does not — most iPhones — the same layout fills the viewport, and Escape leaves it. Either way the document, the page and the zoom survive the move in both directions, the page is redrawn at the size it now has rather than stretched, and focus returns to the control that opened it.
- The four PDF Gizlets gained what the shared surface makes cheap. Image to PDF previews the document it actually generated before you download it. PDF to Image shows the source while pages are being chosen, and the two ways of naming a page are kept in step: the field moves the viewer to the first page it names, a line says whether the page on screen is in the selection, and a button adds it — collapsing runs the way the field takes them, so adding page 6 to `4-5` gives `4-6`. Merge PDF can inspect any one of the documents going in, one at a time, without disturbing the merge. Split PDF can inspect any document the split produced without leaving the Gizlet or losing a download.
- pdf.js is now loaded on demand on every PDF Gizlet, the reader included — it used to be the one page that pulled a megabyte of renderer up front. Nothing carries it until a document is actually there to draw, and the tests that assert this no longer lean on the viewer as a counter-example: the proof that the check can find the library is the same page a moment later, once a document exists.
