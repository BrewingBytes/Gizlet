### Added

- **Favicon Generator** turns one picture into the icon set a site needs: `favicon.ico`, PNGs at 16, 32, 180, 192 and 512 pixels, the HTML for the page head and the icons fragment for a web app manifest — as one ZIP, made on this device. Each size is previewed at the size it will really be, a picture that is not square gets an explicit choice between cropping and fitting, and the ICO is assembled from PNGs so it stays a few kilobytes.
