- The roadmap's text phase now says that the file-digest Gizlet will also check a digest against one somebody published — which is what its registry entry has promised all along, since it has always been described as the way to "check a download is the file it claims to be". Computing a hash and checking one are the same computation with one extra field, so they are one Gizlet on one page rather than two routes to the same arithmetic.
- The phase also records a piece of reuse it had not: the MD5 written by hand for the UUID versions, because the browser's own crypto refuses to provide one, is the same MD5 the digests need for the checksums that are still published as MD5.
